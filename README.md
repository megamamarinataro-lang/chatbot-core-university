# Практика работы с СУБД SQLite на Python

Консольный чат-бот, имитирующий серверную регистрацию пользователей с автоматическим сохранением данных в локальную реляционную базу данных SQLite.

## Инструкция по запуску:
1. Откройте терминал в папке проекта `python_sqlite_practice/`.
2. Запустите  `python console_bot.py`
3. Введите имя и почту пользователя для добавления записи в базу данных.
